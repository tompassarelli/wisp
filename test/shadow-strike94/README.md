# Original Shadow Strike field fixture

These TypeScript sources author two original ability configurations and a
nonattacking, nonregenerating unit through Wisp's object-data encoder. They
contain no extracted metadata, stock object records, assets or game scripts.
The build reads the owner's private base map and writes its output privately.

See [the field reference and capture instructions](../../docs/shadow-strike.md).
Four Classic native reports on build 3.0.0.24268 record 40 initial damage
and 10 periodic damage at one/two-second sampled intervals for `acas=1/2`.
The same Bun and emitted 32-bit Lua journey matches 2/2 configurations and
9/9 damage rows per client. `native-rows.ts` transcribes only the numerical
observations from those four reports. `headless-config.ts` declares the
authored fields and a combined impact delay within the observed bracket;
it does not claim a separately measured cast point or projectile speed.
